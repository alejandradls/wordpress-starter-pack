# 🚀 Starter Pack de Plugins para WordPress

Lista curada de plugins esenciales que utilizo para iniciar proyectos en WordPress, con el objetivo de mantener configuraciones consistentes, sitios ligeros y una base sólida desde el día uno.

Este starter pack está pensado como un **kit de arranque** que puedes adaptar según el tipo de sitio que estés construyendo.

---

## 📥 Descargar el Starter Pack

Descarga el archivo con la lista de plugins (slugs oficiales):

**starter-stack-alejandra.txt**

Este archivo contiene los identificadores de cada plugin para facilitar su instalación.

---

## 🔧 Plugins incluidos

Todos los plugins funcionan correctamente con su **versión gratuita**:

- Autoptimize  
- Smush  
- SVG Support  
- Contact Form 7  
- Honeypot for Contact Form 7  
- UpdraftPlus  
- WP-Optimize  
- iThemes Security  
- LiteSpeed Cache  
- Yoast SEO  

---

## 🧰 Instalación de plugins (WP-CLI)

Si trabajas en local o tienes acceso a servidor, puedes instalar todos los plugins de forma rápida usando **WP-CLI**.

Ejecuta el siguiente comando desde la raíz de tu proyecto WordPress:

```bash
wp plugin install autoptimize wp-smushit svg-support contact-form-7 honeypot-for-contact-form-7 updraftplus wp-optimize better-wp-security litespeed-cache wordpress-seo --activate
